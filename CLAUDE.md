# Розумний телесуфлер

PWA українською: суфлер прокручує текст у темпі голосу (Web Speech API), уміє ручну прокрутку, запис відео з камери і статистику репетицій. Чистий HTML/CSS/JS (ES-модулі), без збірки, без залежностей, без бекенду.

## Запуск

```bash
npm start        # python -m http.server 5173 → http://localhost:5173
npm test         # тести matcher/markup/stats у Node
```

Тести в браузері: http://localhost:5173/tests/index.html.
Мікрофон і камера працюють лише на `localhost` або HTTPS.

## Структура

- `index.html` — оболонка, нижня панель вкладок.
- `js/app.js` — hash-роутинг: `#/`, `#/settings`, `#/script/:id`, `#/play/:id`, `#/record/:id`, `#/history/:id`. Кожен екран — функція `xxxScreen(root, id)`, що повертає cleanup.
- `js/db.js` — IndexedDB: `scripts`, `rehearsals` (індекс `scriptId`), `kv` (налаштування, прапорець демо-сценарію).
- `js/markup.js` — розбір тексту: абзаци (порожній рядок), `[ПОЗНАЧКИ]`, `**наголос**`, `normalizeWord`. Без DOM.
- `js/matcher.js` — `Tracker`: локальне вирівнювання останніх 6 сказаних слів зі сценарієм (з кроком «одне сказане = два злиті слова», збігом основ і слабким збігом за початком слова); пороги стрибків вперед/назад/глобально. Без надійного збігу текст «іде за голосом» (`follow`): слово, що починається як одне з 3 найближчих, посуває позицію, але не далі 6 слів від `sure` — останнього надійного збігу. Без DOM. Зміни перевіряти тестами «швидка мова…» і «за голосом…».
- `js/speech.js` — `SpeechListener`: безперервне розпізнавання з автоперезапуском і сторожем (перезапуск, якщо 7 с немає подій). `onWords(words, text)` — нормалізовані слова й сирий текст (рядок «що чую» під індикатором мікрофона).
- `js/prompter.js` — `Prompter` (рендер, прокрутка через transform, кеш центрів слів), `PromptSession` (голос/ручний режим, підсумок), `bindControls` (кнопки, клавіатура), екран суфлера.
- `js/recorder.js` — камера, `MediaRecorder` (mp4, якщо підтримується, інакше webm), відлік, збереження в обрану папку (File System Access, хендл у `kv/videoFolder`), завантаження/поділитися. У файл пишеться тільки камера.
- `js/stats.js` — слова-паразити, темп, збереження репетицій, графік (SVG), екран історії. Верх файлу — чисті функції.
- `js/settings.js` — налаштування (у пам'яті `settings`, зберігаються в `kv`), екран налаштувань, `prompterView()`.
- `js/ui.js` — іконки, шторки (`sheet`), тости, форматування.
- `sw.js` — кеш оболонки (спершу мережа, кеш — для офлайну). **Новий файл → додати в `ASSETS`.** Змінили склад файлів → збільшити `VERSION`.

## Домовленості

- Інтерфейс і коментарі українською, коментарі короткі.
- Логіку, яку можна тестувати, тримати в модулях без DOM (`markup`, `matcher`, верх `stats`) і покривати тестами в `tests/cases.js`.
- Кольори — CSS-змінні в `css/base.css` (світла/темна тема через `data-theme` на `<html>`); суфлер має власні змінні `--pr-*`, які ставить `Prompter.applyView` на `.pr-screen`.
